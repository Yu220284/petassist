Petassist

大人も子どもも。安心して使えるAIエージェント

Petassist01

Problem

AIエージェントを使ってみたい。
学ばせてみたい。でも…

大事な情報が消されないか心配

権限をすべて渡すか、まったく渡さないか。両極端になりがち…

意図が伝わらず、時間を取られる

頼んでいない場所まで触ってしまい、やり直しに時間がかかる…

触ってほしくないファイルがある

社外秘や大切な個人情報にはアクセスしてほしくない…

Petassist02

Solution

かわいいだけじゃない、使えるデスクペット。

権限は、必要な分だけ渡す。ぺたしすとは、PCの安全を守るアシスタントです。

範囲を決める

使うツールや開けるアプリ・フォルダなど、権限を渡す範囲を絞れます。

確認する

メールや投稿は、ユーザーの承認を待って停止します。

スマホ・PCに対応

シームレスにスマホにも移動して、作業を継続。

Petassist03

How to use

こんな使い方ができます

アシスタントごとに、権限も、使うモデルも変えられます。

01 / ねこ

検索や調べ物

閲覧専門。フォルダやPCの中は見ても、中身は変更不可に。

02 / うさぎ

下書きだけ

返信や告知の文を作って、送る直前でユーザー承認を待機。

03 / いぬ

ツールをつくる

渡したフォルダの中で、ファイル作成やフォルダ整理などを行います。
