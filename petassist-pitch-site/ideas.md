# Petassist デザイン検討

## 3つの方向性

### 1. Permission Garden
**Very Brief Intro**: やわらかな庭の比喩で、権限を「育てる範囲」として見せる。安心感が強く、初めてAIエージェントを使う人への心理的障壁を下げる。  
**Probability**: 0.07

### 2. Workbench of Trust
**Very Brief Intro**: 実際のデスクと付箋を想起させる、触覚的で編集可能なワークベンチ。恐怖を抽象的に語るのでなく、誰がどこまで作業できるかを目の前のUIで理解させる。  
**Probability**: 0.04

### 3. Permission Control Room
**Very Brief Intro**: 強いコントラストと情報密度で、AIを操作可能なシステムとして見せる。高度な利用者には刺さるが、Petassistの親しみやすさを損なう危険がある。  
**Probability**: 0.08

## 採用方針: Workbench of Trust

### Design Movement
**ポストデジタル・ステーショナリー**。ブラウザの中にある無機質な「権限設定」を、デスクの上で手を伸ばして動かせる物に置き換える。ワークスペースの物質感、メモ、マグネット、インクのにじみを使いながら、UIそのものは明確で現代的に保つ。

### Core Principles
1. **見えない権限を、目の前のカードにする。** すべての権限は顔・状態・範囲を持つ一つの具体物として表示する。
2. **危険の説明より、制御の手触りを見せる。** ヒーローで実際にペットと権限の動きを操作できるようにし、価値を一目で伝える。
3. **かわいさと仕事の緊張感を両立する。** 動物は装飾ではなく「誰が実行するか」を識別するレイヤーとして機能させる。
4. **余白には目的を持たせる。** セクションを均一なカード群にせず、デスクの上に置かれた情報物のように、上下・左右のリズムを変える。

### Color Philosophy
基調は少し黄みを帯びた**Desk Paper**（#F7F2E9）と深い**Ink Navy**（#1E2942）。安心の土台となる紙とインクの組み合わせに、承認や行動のシグナルとして鮮明な**Petassist Orange**（#FF6B4A）を一点投入する。権限状態には濁りのないセージ、ブルー、アプリコットを使い、警告を威圧的な赤ではなく「いったん止まる」ための視認性として設計する。

### Layout Paradigm
**ワークベンチの俯瞰図**。ヒーローは中央に整列した紹介文ではなく、左にステートメント、右に実際の「デスク」プロトタイプ、下端に連続する権限チップを置く。以降は横長のマニフェスト帯、三つのペットの作業レーン、最後に横へ伸びる使い方フローを組み合わせる。各領域は紙片やテープのように重なり、一定のカードグリッドを避ける。

### Signature Elements
1. **Permission Tether**: ペットのアイコンから権限バッジや対象フォルダへ伸びる、丸端のカラーライン。
2. **Desk Tape**: セクションの要点を留める、わずかに傾いた半透明のテープ片。
3. **Action Stamp**: `ALLOW`・`DRAFT ONLY`・`OBSERVE` を状態として押印する太い角丸スタンプ。

### Interaction Philosophy
インタラクションは「エージェントを動かす」ことを感じさせつつ、常に予測可能であることを優先する。ペットの選択、タスクの切替、承認ボタンはすべて即時に明確な状態変化を返す。派手なゲーミフィケーションは使わず、選択されたペットのテザーラインと権限ラベルだけを更新する。

### Animation
初回表示では、デスクのペット・権限カード・タスクが 50–80ms 間隔で下からわずかに立ち上がる。ホバー時は紙片が 2px 浮き、ペットは 1–2px の短い上下動で応答する。`ALLOW` は押下時にオレンジのスタンプが 150ms で収まり、強い責任あるアクションとして表現する。すべての動きは `cubic-bezier(0.23, 1, 0.32, 1)` で 300ms 以下、`prefers-reduced-motion` では停止する。

### Typography System
見出しは**DM Serif Display**の太いイタリックと、コンパクトな**Space Grotesk**の組み合わせ。本文とUIラベルは Space Grotesk を使い、作業領域のコード、パス、権限には **IBM Plex Mono** を使う。ヒーローの見出しは 60–88px、章見出しは 38–56px、UIラベルは追い込みのある 11–12px 大文字を原則とする。

### Brand Essence
**Petassistは、仕事を任せる範囲を一目で把握できる、デスクに常駐するAIチームメイト。**  
Personality: **tactile / reassuring / precise**

### Brand Voice
断言はするが脅さない。機能の説明ではなく、ユーザーが握れるコントロールを主語にする。見出しは短く、CTAは具体的な行為を示す。  
Example: 「任せる。でも、丸投げしない。」  
Example: 「外に出す前に、あなたが決める。」

### Wordmark & Logo
ワードマークは `pet` をインクネイビー、`assist` をオレンジで組み、`t` のクロスバーをPermission Tetherの始点にする。シンボルは、動物の耳のような二つの角を持つ丸い付箋ピン。顔ではなく「デスクに留め、範囲を見せる」記号として機能させる。

### Signature Brand Color
**Petassist Orange — #FF6B4A**。ユーザーの注意と最終判断を示す、温かく明確なブランドシグナル。

## Style Decisions

- **Permission Tether** はすべての主要セクションで、ペットの識別子から権限状態またはワークスペース境界までを目に見える形でつなぐ、反復的な構造モチーフとする。
- **Petassist Orange — #FF6B4A** は、プライマリCTA、承認スタンプ、境界警告、テザーの終点など、ユーザーの最終判断を示す瞬間に限定する。
- 全セクションに、テープ・スタンプ・ピン留めメモ・レーンカード・テザー・紙の重なりのいずれかを置き、一般的なSaaSのグリッドへ戻らないようにする。
